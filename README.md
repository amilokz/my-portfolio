## ✨ About This Project

An **interactive 3D portfolio** showcasing my journey as a full-stack developer. Built with modern web technologies to create an immersive user experience that stands out from 99% of portfolios.

### 🎯 Key Features

- 🎨 **Immersive 3D Graphics** - Powered by Three.js with a fully interactive solar system
- ✨ **Butter-smooth Animations** - Framer Motion brings every interaction to life
- 🤖 **AI ChatBot Assistant** - Intelligent assistant to answer questions about my work
- 🎤 **Voice Commands** - Navigate using voice (supports English & Urdu)
- 📄 **AI Resume Scanner** - Get instant feedback on your resume
- 💻 **Code Playground** - Write and test JavaScript code in real-time
- ⌨️ **Typing Speed Test** - Test your typing skills with live feedback
- 🎯 **AI Project Recommendations** - Smart suggestions based on your interests
- 📱 **Fully Responsive** - Perfect experience on all devices (mobile, tablet, desktop)
- 🌙 **Dark/Light Mode** - Seamless theme switching with persistence
- ⚡ **Blazing Fast** - Optimized with Vite for instant load times
- 📊 **Live GitHub Stats** - Real-time GitHub activity and contributions
- 🔔 **Cookie Consent** - GDPR compliant cookie management
- 📤 **Share Portfolio** - One-click sharing on social media
- 📱 **PWA Support** - Install as a native app on mobile devices

## 🏃‍♂️ Run Locally

```bash
# Clone the repository
git clone https://github.com/amilokz/my-portfolio.git

# Navigate to project
cd my-portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Deploy to GitHub Pages
npm run deploy
Open http://localhost:5173 to view it in your browser.
