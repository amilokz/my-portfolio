## ✨ About This Project

An **interactive 3D portfolio** showcasing my journey as a full-stack developer. Built with modern web technologies to create an immersive user experience that stands out.

### 🎯 Key Features

- 🎨 **Immersive 3D Graphics** - Powered by Three.js for stunning visual effects
- ✨ **Butter-smooth Animations** - Framer Motion brings every interaction to life
- 📱 **Fully Responsive** - Perfect experience on all devices (mobile, tablet, desktop)
- ⚡ **Blazing Fast** - Optimized with Vite for instant load times
- 🎭 **Dynamic Project Showcase** - Easy to update and maintain
- 🔍 **SEO Friendly** - Meta tags and semantic HTML

## 🏃‍♂️ Run Locally

```bash
# Clone the repository
git clone https://github.com/amilokz/my-portfolio.git

# Navigate to project
cd my-portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
Open http://localhost:5173 to view it in your browser.

🌐 Deployment
This portfolio is automatically deployed to GitHub Pages using GitHub Actions.

Live URL: https://amilokz.github.io/my-portfolio/

Deployment Branch: gh-pages

Source Branch: source-code

Every push to the source-code branch triggers a new deployment automatically.
